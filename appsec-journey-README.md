# appsec-journey

Мой путь из backend-разработки (Go, Python) в Application Security.

Здесь — конспекты, учебные проекты и разборы уязвимостей. Каждая тема проходит один цикл: **теория → эксплуатация → уязвимый код → исправление → разбор**.

## Обо мне

- 4 года backend-разработки на Go и Python, включая высоконагруженные системы
- Фокус: безопасность веб-приложений и API, безопасная разработка, DevSecOps

## План

1. **Фундамент** — HTTP, CORS, TLS, криптография, аутентификация
2. **Веб-уязвимости** — OWASP Top 10, OWASP API Security Top 10, PortSwigger Web Security Academy
3. **Безопасный код и ревью** — типичные ошибки в Go и Python, security code review, моделирование угроз
4. **DevSecOps** — SAST, SCA, DAST, поиск секретов, безопасность контейнеров, пайплайн в CI
5. **Российская специфика и безопасность ИИ** — ГОСТ Р 56939-2024 (РБПО), OWASP Top 10 for LLM
